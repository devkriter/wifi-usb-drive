Setup network

The drive can open its own network WiFi-Drive-XXXX (default password wifidrive) and show a join QR code on its screen. It does this by itself when it cannot reach your WiFi; start it here to show the QR code now, for example to connect a phone. On the setup network this page is at http://192.168.4.1/settings.html.
